# HIT Publication Statistics

Public GitHub Pages repository for the anonymized HIT publication statistics dashboard.

This repository intentionally contains only:

- `index.html`: standalone browser dashboard with embedded anonymized aggregate data
- `.nojekyll`: GitHub Pages static serving marker

It does not contain the original Excel workbook, raw author names, paper titles, journal title fields, DOI worklists, audit JSONL/CSV files, or parsing/enrichment source data.
